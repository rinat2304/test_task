# Snapbuild — тестовое задание

Развитие продуктового лендинга Snapbuild в рамках тестового задания на позицию Junior Fullstack Developer.

## О проекте

В рамках задания был разработан и расширен лендинг Snapbuild — AI-платформы для создания сайтов, изображений, видео, баннеров и презентаций в рамках единой дизайн-системы бренда.

Основная задача была не просто добавить новые компоненты, а продолжить существующий визуальный язык продукта так, чтобы новые блоки воспринимались как естественная часть исходного лендинга.

## Локальный запуск

Для запуска проекта локально:

```bash
npm install
npm run dev
```

После запуска приложение будет доступно по адресу, который укажет Vite в терминале.

Для проверки production-сборки:

```bash
npm run build
npm run preview
```

## Добавленные секции

В рамках задания были разработаны следующие новые секции:

### 1. Product Overview

Блок с основными возможностями платформы: создание контента, единый бренд, быстрая адаптация и работа разных команд.

### 2. Campaign Flow

Пошаговый сценарий работы с продуктом — от идеи до публикации готовой кампании.

### 3. Team Switcher

Интерактивная секция для разных команд: маркетинга, дизайна, продукта и продаж.

### 4. Design System

Секция, объясняющая роль дизайн-системы бренда при создании нового контента.

### 5. Variations

Интерактивный блок с переключением между форматами контента: сайт, баннер, Social и презентация.

Дополнительно реализована финальная форма демонстрации продукта с базовой валидацией и состоянием успешной отправки.

## Анализ стилистики исходного сайта

Перед разработкой новых секций был проанализирован существующий лендинг Snapbuild.

В качестве основных визуальных ориентиров использовались:

* минималистичная композиция;
* большое количество свободного пространства;
* крупная типографика;
* нейтральная цветовая палитра;
* мягкие серые поверхности;
* тонкие границы;
* крупные скругления;
* pill-shaped кнопки и переключатели;
* ограниченная визуальная иерархия;
* спокойные hover-анимации;
* повторяемая система отступов;
* последовательное использование карточек и контейнеров.

Новые секции строились на тех же визуальных паттернах, чтобы страница воспринималась как единый продуктовый лендинг.

## Что удалось воспроизвести

В проекте были воспроизведены и продолжены основные визуальные принципы исходного лендинга:

* шапка сайта;
* hero-блок;
* крупная типографика;
* CTA-кнопки;
* светлые и серые секции;
* карточные композиции;
* разделители;
* интерактивные переключатели;
* hover-состояния;
* адаптивная сетка;
* мобильная версия;
* финальный CTA и форма.

При этом новые блоки не копируют существующие секции буквально, а используют их визуальный язык и композиционные принципы.

## Что не удалось реализовать

Полное воспроизведение всех внутренних секций и функциональности исходного продукта не входило в основной объём работы.

Также в рамках задания не реализовывались:

* реальная серверная отправка формы;
* авторизация;
* backend;
* интеграция с AI API;
* реальные генерации контента;
* внутренняя функциональность платформы.

Форма демонстрации работает на стороне клиента и содержит валидацию полей и состояние успешной отправки, что соответствует требованиям задания.
